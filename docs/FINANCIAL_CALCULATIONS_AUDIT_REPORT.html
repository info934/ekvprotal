Audit finančních výpočtů EKV Portalu

Statický auditní report pro projekce, realizace, výplaty, hodinové mzdy, režijní alokace a CRM doklady. Reálná data jsou anonymizovaná a slouží jen jako kontrolní vzorek.

Vygenerováno: 2026-06-21 Model: paid-only Data: anonymizovaná lokální DB + DEMO-FIN

Finanční pravidla

Projekce

gross_project_budget = price * budget_percentage / 100

planned_team_budget = gross - planned_overhead - subcontractors

cost_adjusted = planned_team_budget - direct_costs - allocated_overhead

Výplaty

team_budget_after_paid = cost_adjusted - paid_payouts

available = calculated_reward - reserved_or_paid

Rezervace blokují další žádost, ale nejsou náklad.

Realizace

team_budget = total_revenue - profit - overhead - operational_costs - paid_payouts

Nezaplacená hodinová práce je expozice, ne náklad.

Nálezy a akceptační pravidla

  • UI nesmí používat lokální finanční helper jako autoritativní hodnotu pro výplatu, schválení nebo uzavření workflow.
  • Projektové odměny se mají zobrazovat proti budgetu po paid výplatách, pokud je backend summary dostupný.
  • Realizační a projektová hodinová práce zůstává expozice do momentu, kdy odpovídající hodinová výplata přejde do stavu paid.
  • Režijní alokace se ukládají přes RPC a schválení provádí účetní zápis atomicky.
